What the PDF asked you to build

The task was to create LogLens, a command-line tool that:

1. Reads log files from multiple services.
2. Supports two log formats:
   - Plain text logs
   - JSON-line logs
3. Handles different time zones and converts them to one timezone.
4. Groups requests into fixed 5-minute windows.
5. Calculates:
   - Request count
   - Error rate
   - p50 latency
   - p95 latency
6. Detects incidents:
   - Error rate above 5% with at least 20 requests
   - p95 latency above 2,000 ms for two consecutive windows
7. Combines consecutive alert windows into one incident.
8. Produces CSV and JSON reports.
9. Allows filtering by service and time range.
10. Includes tests, documentation, a design note, AI usage note, and presentation.
